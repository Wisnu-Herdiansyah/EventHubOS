# Threat model (Phase 0 / Phase 1 slices: tenancy, events, identity)

Scope: control-plane API, admin web app (BFF), PostgreSQL, outbox relay. Method: STRIDE per trust boundary.
Revisit when adding public delivery (Phase 2), domains (Phase 3), billing/webhooks (Phase 4).

## Assets

Tenant business data; membership/role assignments; session tokens and cookies; audit evidence;
database credentials; outbox payloads.

## Trust boundaries

1. Internet → API (untrusted clients). 2. API → PostgreSQL (runtime role). 3. Worker →
   PostgreSQL and broker. 4. Operators → migration/bootstrap roles. 5. Browser → admin web app
   (untrusted; session cookie) → API (bearer token, trusted proxy for client IP).
